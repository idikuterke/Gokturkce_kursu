# s. 87 — ORHON TÜRKÇESİ GRAMERİ

- *biti-* "yazmak" (KT GD, vb.) < **bit* "yazı fırçası" < Çin. *pi* < **piet* "fırça"
- *tokı-* "dövmek, savaşta mağlup etmek" (BK G 8, vb.) < **tok* yansıma

- *yorı-* "yürümek" (KT D 37, vb.) < **yor* (krş. MK *yorçı* "kılavuz, rehber, yol gösteren", Mo. *corçi-* "gitmek, yürümek, gezmek")
