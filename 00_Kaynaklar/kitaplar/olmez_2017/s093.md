# s. 093 — Köktürkçe Dersleri (basılı sayfa numarası 95)

çoğalttım. Bu sözümde (hiç)"

- sav: isim tabanı
- +(ı)m: teklik birinci kişi iyelik eki
- +da: bulunma/ ayrılma durumu eki

**ığid bargu türük begler** < *beg+ler* "yalan var mı? Türk beyleri"
- beg: isim tabanı
- +ler: çoğluk eki
- bar: isim tabanı
- +gu: soru edatı

**bodun boŋı ėşidiŋ** < *ėşid-(i)ŋ* "halkı bunu dinleyin"
- ėşid-: fiil tabanı
- -(i)ŋ: teklik ikinci kişi emir eki

**türük bodun terip** < *tėr-ip* "Türk halkını derleyip"
- tėr-: fiil tabanı
- -(i)p: zarffiil eki

**ėl tutsıkıŋın** < *tut-sık+(ı)ŋ+(ı)n* "ülke kuracağınızı"
- tut-: fiil tabanı
- -sık: gelecek zaman-gereklilik sıfatfiil eki
- +(ı)ŋ: teklik ikinci kişi iyelik eki
- +(ı)n: iyelik ekinden sonra gelen belirtme durumu eki

**boŋta** < *bo+n+ta* "buraya"
- bo: isim tabanı
- +n: zamir n'si
- +ta: bulunma/ ayrılma durumu eki

**urtum** < *ur-tu+m* "kazıdım"
- ur-: fiil tabanı
- -tu: bilinen geçmiş zaman eki
- +m: teklik birinci kişi eki

**yaŋılıp** < *yaŋıl-(ı)p* "hata edip"
- yaŋıl-: fiil tabanı
- -(ı)p: zarffiil eki

**ölsıkiŋin yeme** < *yem-e* "öleceğinizi de"
- yem-: fiil tabanı
- -e: zarffiil eki; kalıplaşarak edat oluşturmuştur
