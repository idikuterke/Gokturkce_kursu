# s. 094 — Mehmet Ölmez (basılı sayfa numarası 96)

(Runik metin: KT G 11)

*G 11. bonta : urtum : neŋ neŋ : savım : erser : beŋgü : taşka : urtum : aŋar körü biliŋ : türük : amtı bodun : begler : bödke körügme : beglergü : yaŋıltaçı siz men : beŋgü : taş tikdim : tavgaç : kaganta : bedizçi kelürtüm : bedizettim : meniŋ : savımın : sımadı :*

"buraya kazıdım. Söyleyecek ne sözüm varsa bengi taşa kazıdım. Buna bakarak anlayın. Şu anki Türk halkı, beyleri, halihazırdaki beyler, sizler mi yanılacaksınız? Ben bengi taş diktim. Çin hakanından sanatçı getirttim, nakşettirdim. Çin hakanı benim sözümü kırmadı,"

**bonta urtum neŋ neŋ savım erser beŋgü taşka** < *taş+ka* "buraya kazıdım. Söyleyecek ne sözüm varsa bengi taşa"  
- taş: isim tabanı  
- +ka: yaklaşma/ bulunma durumu eki  

**urtum aŋar** < *\*an+garu* "kazıdım. Buna"  
- \*an: muhtemel isim tabanı  
- +garu: yön gösterme durumu eki  

**körü biliŋ türük amtı bodun begler bödke körügme** < *kör-(ü)gme* "bakarak anlayın. Şu anki Türk halkı beyleri, halihazırdaki"  
- kör-: fiil tabanı  
- -(ü)gme: şimdiki zaman sıfatfiil eki  

**beglergü** < *beg+ler+gü* "beyler"  
- beg: isim tabanı  
- +ler: çokluk eki  
- +gü: soru edatı  

**yaŋıltaçı siz** < *yaŋıl-taçı siz* "sizler mi yanılacaksınız"  
- yaŋıl-: fiil tabanı  
- -taçı: gelecek zaman eki  
- siz: çokluk ikinci kişi eki  

**men beŋgü taş tikdim** < *tik-di+m* "ben bengi taş diktim"  
- tik-: fiil tabanı  
- -di: bilinen geçmiş zaman eki  
- +m: teklik birinci kişi eki  

**tavgaç kaganta** < *kagan+ta* "Çin hakanından"
