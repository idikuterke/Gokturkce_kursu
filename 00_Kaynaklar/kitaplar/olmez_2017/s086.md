**G 6.** *edgü bilge : kişiğ : edgü : alp kişiğ : yorıt-maz : ermiş : bir kişi : yaŋılsar : uguşı : bodunı : böşükiŋe tegi : kıd-maz ermiş : süçig : savıŋa : yemşak : agısıŋa : arturup : üküş : türʰk : bodun : öltiiŋ türʰk : bodun : ölsikiŋ : bėriye : çugay : yış : tögültün :*

> "Bilgili ve yiğit insanları ilerletmezlermiş. Bir kişi suç işlerse bütün kavmini, halkını, akrabalarına varıncaya kadar öldürmezlermiş. Tatlı sözlerine, yumuşak ipeklerine kanıp Türk halkından birçoğunuz öldünüz. Türk halkı, mutlaka öleceksin! Güneye Çugay dağlarına, Tögültün"
